Magic Frame App

help

Use this app to generate perforated images and an overlaying screen. When the screen is shifted slightly, either of the images is hidden allowing you to magically change the picture. The images can then be printed on transparency paper. The magic frame or its plans are available to purchase here

File: load examples, download an image file for printing. Save your projects data as a text file to upload to upload later.

Frame Settings: Set the size of your frame. The default size suits the standard available picture frame.

State 1 and 2: Set your 2 messages by typing in the text field. Or upload an image. The image must be a silhoette with an alpha channel. (that means no pixels in the white areas)
